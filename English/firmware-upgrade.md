# Firmware upgrade

Download the newest firmware file

[!file Firmware version v1.1.0, release date 07. September 22](/static/v1.1_OTA.bin)



Changelog:

- V1.1.0 : New top up function, improved web interface to better fit mobile screens, bug fixes


!!!
Never use firmware files of unknown origin and/or of another origin than this page 
!!!



### How to upgrade

First check your current version number at the bottom of the menu page:

![](/static/menu.png)

Go to "Update firmware", select the firmware file (the downloaded *.bin file) and press upload. Please never unplug the filler while the firmware upgrade is in progress. When the upgrade is completed the leds will flash when the filler reboots after the upgrade. It's not necessary to reboot the filler manually after the firmware upgrade.

![](/static/firmware.png)
